## Overview

Connect Agentforce to Cekura to run chat evaluations against your agent, test your Agentforce Voice agent by calling its phone number, and monitor production Agentforce Voice calls automatically.

<Note>
Cekura cannot start outbound calls from an Agentforce Voice agent. For voice testing, Cekura calls your agent's inbound phone number.
</Note>

## Prerequisites

- An Agentforce agent and its Agent ID
- A Salesforce External Client App with the Client Credentials Flow enabled
- Your Salesforce My Domain URL, for example `https://example.my.salesforce.com`
- For voice: an Agentforce Voice phone number

## Set up the External Client App in Salesforce

<Steps>
  <Step title="Add OAuth scopes">
    In **Setup → External Client App Manager**, open your app and edit its OAuth settings. Add these scopes:

    - Manage user data via APIs (`api`)
    - Perform requests at any time (`refresh_token`, `offline_access`)
    - Access chatbot services (`chatbot_api`)
    - Access the Salesforce API Platform (`sfap_api`)

    Enable **Client Credentials Flow** and **Issue JSON Web Token (JWT)-based access tokens for named users**, then save.
  </Step>

  <Step title="Set the Run As user">
    On the app's **Policies** tab, enable **Client Credentials Flow** and set **Run As** to a dedicated integration user.
  </Step>

  <Step title="Connect the app to your agent">
    In **Setup → Agentforce Agents**, open your agent, go to **Connections**, add an **API** connection, and select the External Client App.
  </Step>

  <Step title="Grant voice call access">
    To import Agentforce Voice calls, give the Run As user read access to **Voice Calls**, **Voice Call Recordings**, and conversation entries. Turn on call recording in your Agentforce Voice setup if you want Cekura to import recordings.
  </Step>
</Steps>

<Note>
Salesforce can take a few minutes to apply changes to an External Client App.
</Note>

## Connect Agentforce in Cekura

In Cekura, go to **Agents**, create an agent, and select **Agentforce** as the provider.

<img src="/images/agentforce/select-provider.png" alt="Select Agentforce as the agent provider in Cekura" />

Enter the following and save the agent:

| Field | Value |
| --- | --- |
| **Agentforce Client ID** | The External Client App's consumer key |
| **Agentforce Client Secret** | The External Client App's consumer secret |
| **Agentforce Domain** | Your My Domain URL, without a trailing slash |
| **Agentforce Agent ID** | The ID of your Agentforce agent |

<img src="/images/agentforce/integration-settings.png" alt="Agentforce integration settings in Cekura" />

Enable **Auto-sync Prompts** to keep the agent description in sync with your Agentforce agent. Every 5 minutes, Cekura reads the active agent version from Salesforce and rebuilds the description from the agent's description and each topic's description and instructions. Cekura also imports the agent name and language. If the credentials stop working or the agent is deleted, auto-sync turns itself off.

To create an agent from Agentforce through the API, call `POST /v2/aiagents/` with `provider.type` set to `agentforce`, `provider.configure_from_provider` set to `true`, and the Client ID, Client Secret, Domain, and Agent ID under `provider.chat_agent_details.config`.

## Chat testing

Open an evaluator, click **Run**, select **Chat** under **Connections**, and start the run. Cekura starts an Agentforce session for each conversation and records the transcript and metrics in the result.

<img src="/images/agentforce/configure-run-chat.png" alt="Configure Run dialog with Agentforce chat selected" />

See [Chat Testing](/documentation/integrations/chat-testing) for more details.

## Voice testing

To test your Agentforce Voice agent, enter its phone number under **Telephony Settings**, keep **Inbound** enabled, and save the agent. Run an evaluator using the **Telephony** connection, and Cekura calls the agent's number for each test.

<img src="/images/agentforce/telephony-settings.png" alt="Agentforce telephony settings in Cekura" />

## Monitor production calls

Enable **Auto-fetch Calls** in the Agentforce provider settings to import completed Agentforce Voice calls automatically.

<Steps>
  <Step title="Configure the phone number">
    Enter the Agentforce Voice phone number under **Telephony Settings**. Cekura imports only calls made to or from this number.
  </Step>

  <Step title="Enable Auto-fetch Calls">
    Turn on **Auto-fetch Calls** and save the agent.

    <img src="/images/agentforce/auto-fetch-production-calls.png" alt="Enable Agentforce production call auto-fetch in Cekura" />
  </Step>

  <Step title="Review imported calls">
    Open **Calls** in Cekura to review each call's transcript, recording, duration, end reason, and metric results.

    <img src="/images/agentforce/imported-call.png" alt="Imported Agentforce Voice call with transcript and recording" />
  </Step>
</Steps>

<Note>
If a call has no recording in Salesforce, or the Run As user cannot read it, Cekura still imports the transcript and call details.
</Note>

## Troubleshooting

- **`invalid_grant: no valid scopes defined`**: the External Client App has no OAuth scopes. Add the scopes listed above and enable the Client Credentials Flow.
- **No calls are imported**: check that the phone number in Cekura matches the Agentforce Voice number, and that the Run As user can read Voice Calls.
- **Calls import without recordings**: turn on call recording in your Agentforce Voice setup and give the Run As user access to Voice Call Recordings.
