## Overview

If your voice agent is built on [LiveKit Agents](https://docs.livekit.io/agents/) and uses [AssemblyAI](https://www.assemblyai.com/) for speech-to-text, connect it to Cekura with the [LiveKit integration](/documentation/integrations/livekit/testing). Cekura joins a LiveKit room as the caller, your agent transcribes the caller with AssemblyAI, and every run is scored with your metrics.

## Prerequisites

- A LiveKit agent deployed to LiveKit Cloud or your own LiveKit server, with an explicit **agent name** so Cekura can dispatch it.
- LiveKit API key, API secret, and server URL.
- AssemblyAI STT configured in the agent, through LiveKit Inference or the AssemblyAI plugin.

## Use AssemblyAI STT in your LiveKit agent

<Tabs>
<Tab title="LiveKit Inference">

No separate AssemblyAI API key is needed; usage is billed through LiveKit Cloud.

```python
from livekit.agents import AgentSession, inference

session = AgentSession(
    stt=inference.STT(model="assemblyai/universal-3-6-pro", language="en"),
    # ... llm, tts, vad, etc.
)
```

</Tab>
<Tab title="AssemblyAI plugin">

Install the plugin and set `ASSEMBLYAI_API_KEY` in your agent's environment.

```shell
uv add "livekit-agents[assemblyai]~=1.8"
```

```python
from livekit.agents import AgentSession
from livekit.plugins import assemblyai

session = AgentSession(
    stt=assemblyai.STT(model="universal-3-6-pro"),
    # ... llm, tts, vad, etc.
)
```

</Tab>
</Tabs>

See the [LiveKit AssemblyAI STT guide](https://docs.livekit.io/agents/models/stt/assemblyai/) for the available models and parameters.

## Connect the agent in Cekura

<Steps>
  <Step title="Select LiveKit">
    In Cekura, go to **Agents**, create an agent, and select **LiveKit** as the provider.
  </Step>
  <Step title="Enter the LiveKit credentials">
    Enter your **LiveKit API Key**, **LiveKit API Secret**, **LiveKit URL**, and the **Agent Name** your AssemblyAI-powered agent is registered under. See [LiveKit (Automated)](/documentation/integrations/livekit/testing) for every field.
  </Step>
  <Step title="Run evaluators">
    Open an evaluator, click **Run**, and select **WebRTC** under Voice connections. Cekura creates a room per run, dispatches your agent, and plays the scenario as the caller.
  </Step>
</Steps>

## Tips

- Use [LiveKit tracing](/documentation/integrations/livekit/tracing) to send your agent's own transcript, tool calls, and latency to Cekura alongside each run.
- Include accents, background noise, and interruptions in your test profiles to check how AssemblyAI transcription and turn detection hold up.
- If the agent never joins the room, confirm the **Agent Name** matches the name the agent registers with and that the agent worker is running.
