Two-factor authentication (2FA), also called multi-factor authentication (MFA), adds a one-time code from an authenticator app to the Cekura sign-in flow. Users configure 2FA individually, and organization admins can require it for everyone in the organization.

## Before you begin

- Install a time-based one-time password (TOTP) authenticator app, such as Google Authenticator or Authy.
- Sign in to the [Cekura dashboard](https://dashboard.cekura.ai).
- You must be an organization admin to enforce 2FA for the whole organization.

<Warning>
Before enforcing 2FA organization-wide, notify your users and ask them to complete their account setup. After enforcement is enabled, users who have not configured 2FA must finish setup before they can continue using the organization.
</Warning>

## Enable 2FA for your account

Each user must enroll their own authenticator app.

1. Open [Account Settings](https://dashboard.cekura.ai/settings).
2. Find the **Two-Factor Authentication** card. The **MFA Status** shows whether protection is enabled, disabled, or awaiting verification.
3. Select **Enable MFA**.

<Frame caption="Enable MFA from the Two-Factor Authentication card in Account Settings.">
  <img src="/images/two-factor-authentication-account.jpg" alt="Cekura Account Settings showing disabled MFA status and the Enable MFA button" />
</Frame>

4. In your authenticator app, add a new account and scan the QR code shown by Cekura.
5. If you cannot scan the QR code, select **Unable to scan?** and enter the displayed manual setup key in your authenticator app.
6. Enter the current six-digit verification code generated by the authenticator app. Cekura verifies the code after all six digits are entered.
7. Confirm that **MFA Status** changes to **Enabled**.

<Note>
Authenticator codes expire quickly. If a code is rejected, wait for the next code and make sure your device date and time are set automatically.
</Note>

### Resume an incomplete setup

If the status is **Unverified**, the authenticator factor was created but setup was not completed. Select **Reload QR Code**, scan the new QR code, and enter the six-digit code to finish enrollment.

## Require 2FA for the organization

Only an organization admin can change this setting.

1. Make sure 2FA is already enabled on your own account.
2. Open [Organization Settings](https://dashboard.cekura.ai/settings/org/general).
3. Find **Require 2FA for All Users**.
4. Turn the switch on.

<Frame caption="Require every member of the organization to use 2FA.">
  <img src="/images/two-factor-authentication-organization.jpg" alt="Cekura Organization Settings showing the Require 2FA for All Users switch" />
</Frame>

5. Select **Save Changes** at the top of the page.
6. Confirm that the dashboard shows **Organization settings updated successfully**.

After enforcement is enabled:

- Users who have not enrolled are directed to the 2FA setup flow.
- Enrolled users are asked for the current six-digit authenticator code when additional verification is required.
- A user cannot continue into the organization until the required 2FA step is complete.

<Tip>
Share the [account setup link](https://dashboard.cekura.ai/settings) with all organization members before turning on enforcement.
</Tip>

## Verify the rollout

1. Ask a member to sign out and sign back in.
2. Confirm that a member without 2FA is prompted to set it up.
3. Confirm that a member with 2FA can enter their authenticator code and access the organization.
4. Ask each member to verify that their **MFA Status** is **Enabled** in [Account Settings](https://dashboard.cekura.ai/settings).

## Disable or reset 2FA

Users can select **Disable MFA** from the **Two-Factor Authentication** card in Account Settings. If the organization requires 2FA, the user must enroll again before continuing to use the organization.

If a user loses access to their authenticator app and cannot sign in, contact [Cekura Support](mailto:support@cekura.ai) for assistance.

## Troubleshooting

### I cannot see the organization enforcement setting

The **Require 2FA for All Users** control is an organization-level setting. Confirm that you are an admin of the selected organization and that you opened **Settings → Organization → General**.

### The verification code is rejected

- Enter the newest code displayed by the authenticator app.
- Make sure the phone or device running the authenticator app uses automatic date and time.
- Check that you scanned the latest QR code if setup was restarted.

### The QR code is no longer available

If the MFA status is **Unverified**, select **Reload QR Code** to generate a new code and complete enrollment.

## Recommended rollout checklist

- Enable 2FA for all organization admins first.
- Tell members when enforcement will begin.
- Share this guide and the [Account Settings](https://dashboard.cekura.ai/settings) link.
- Turn on **Require 2FA for All Users** and save the organization settings.
- Verify the flow with both an enrolled user and a user who has not yet enrolled.
